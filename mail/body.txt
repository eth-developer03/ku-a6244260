BUSINESS IDEAS
1. Java patch blast-radius scanner for Spring Boot services (score 4.8; effort 2, cost 1, fit 5)
   A CLI and GitHub Action that reads a Maven or Gradle project, determines which JDK and library versions it uses, and reports which services are affected by a given CVE and what upgrade path is needed. Small Indian SaaS teams pay a per-repo annual subscription.
   Why now: Java4Shell is a critical Base64 decoder flaw in OpenJDK, and Cloudflare is shipping WAF rules as a stopgap, so teams need to know which of their services are exposed right now.
   First step: Write a script that lists the JDK version and Base64 usage across five of your own Spring Boot repos and produces a risk table.

2. Extraction-yield dashboard for diagnostic-lab report OCR (score 4.2; effort 3, cost 2, fit 5)
   A per-lab dashboard that shows how many fields from scanned lab PDFs were extracted correctly, which were missed, and where errors cluster by report template. Sold per diagnostic chain or clinic to Indian labs digitising historical reports into their HIS.
   Why now: Open-weight extraction models are now available for self-hosting, so labs can run extraction themselves but still need a way to measure yield before trusting it.
   First step: Collect 50 anonymised or synthetic scanned lab reports from two common formats and hand-label the expected fields to create a ground-truth set.

3. Customer-level tests stored as data for AI-generated backend code (score 4.2; effort 2, cost 1, fit 4)
   A test harness where acceptance tests are stored as YAML or JSON scenario files outside the codebase, so coding agents cannot edit them. It runs against Spring Boot services in CI and sells to teams using AI coding agents in production.
   Why now: Fowler's write-up on tests as data and his note on code health cutting review and fix costs by 22 to 35% both point to a need for review-proof test contracts in agent workflows.
   First step: Convert the acceptance tests for one existing Spring Boot endpoint into a JSON scenario file and write a runner that executes it in CI.

4. Employee medical-claim payouts with approval delays for large amounts (score 3.8; effort 3, cost 2, fit 4)
   A mid-market HR add-on that reimburses employee medical and benefit claims through UPI or IMPS, with per-claim limits and an optional hold window for large payouts. The company pays a monthly fee per employee, and the product also tracks reimbursement status.
   Why now: Flex's engineer #1 story shows how painful HSA and FSA payment flows are, and a withdrawal-authorization design with delays for large payouts gives you a model for safe release controls.
   First step: Map the claim-to-payout flow of one Indian SME's reimbursement process and identify which step currently takes the longest.

5. On-prem clinical documentation drafter for small hospitals (score 3.2; effort 4, cost 3, fit 4)
   A self-hosted assistant that drafts discharge summaries and visit notes from doctor dictation and existing records, running on the hospital's own server. The doctor reviews and signs every draft, and no patient text leaves the premises.
   Why now: Recent reports of data-processing incidents at inference providers make it harder for hospitals to justify sending patient notes through third-party model APIs.
   First step: Interview three doctors or medical records staff at small clinics you know through your internship to list the three documents they rewrite most often.
