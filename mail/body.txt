BUSINESS IDEAS
1. Discharge summary drafter for small Indian hospitals (score 4.2; effort 3, cost 2, fit 5)
   A web tool that takes a patient's inpatient notes, lab results and medication orders from the hospital's existing records and drafts a discharge summary in the hospital's own template. The treating doctor reviews, edits and signs every draft, and the tool exports to PDF and DOCX for hospitals that file paper or print records.
   Why now: A recent npj Digital Medicine study found AI can help draft discharge summaries for long, complex stays, which makes this a credible workflow to build and validate now.
   First step: Ask two or three hospital contacts for anonymised discharge summary templates and the fields their staff fill in by hand.

2. SSH and credential exposure auditor for developer machines (score 4.2; effort 2, cost 1, fit 4)
   A small CLI that lists every credential, SSH agent socket and cloud token a local machine exposes to desktop AI apps and to the remote hosts they connect to, then flags anything forwarded unexpectedly. Small dev teams and security consultancies pay for a per-seat or per-team report and a policy file that blocks specific forwards.
   Why now: ChatGPT Desktop was reported to forward the user's SSH agent to remote machines, which shows AI desktop tools can silently widen credential reach, and teams now need a way to check what their tools can see.
   First step: Set up a macOS VM with an SSH agent loaded, connect a desktop AI app to a remote host, and record what the remote side can access through the forwarded socket.

3. GPU price comparison and routing advisor for AI startups (score 4.2; effort 2, cost 1, fit 4)
   A service that continuously tracks hourly prices for the same GPUs across cloud and neocloud providers, estimates cost per token for each workload profile, and suggests the cheapest provider that meets latency needs. It sells as a monthly subscription to Indian AI startups that run inference or fine-tuning and need to control spend.
   Why now: The same H100 is listed between $2.69 and $12.29 per hour depending on the provider, a spread big enough that a tracker could save startups real money.
   First step: Script a daily scraper for the public hourly prices of three providers offering H100s and log the spread for two weeks to show the gap is consistent.

4. Bank-rail reimbursement API for Indian SMEs (score 4.0; effort 3, cost 3, fit 5)
   An API and dashboard where small Indian companies upload employee medical or travel claims, the system checks bills against policy limits, and it pays approved amounts to employee bank accounts over IMPS or UPI. Revenue comes from a per-payout fee, and a licensed payment partner handles the regulated money movement.
   Why now: Payments Canada's launch of its real-time rail and Flex's work on HSA and FSA payment problems both point to instant, rules-based payouts for employee benefits, and India's real-time rails already allow this without new infrastructure.
   First step: Check RBI's payment aggregator rules and talk to two licensed payout providers about a white-label or partner arrangement before writing any payout code.

5. On-prem radiology report structurer for diagnostic centres (score 3.2; effort 4, cost 3, fit 4)
   A self-hosted service that converts a radiologist's free-text report into a structured, consistent format with fields for measurements and findings, running fully on the centre's own hardware. The radiologist remains the sole author and approves every report, and the product sells as a licence plus support to diagnostic chains that cannot send scans or reports to a cloud API.
   Why now: An agentic radiology framework that calls modular tools to produce structured reports shows the approach is maturing, and quantised models like Maple now run useful sizes on a 6GB consumer GPU, so on-prem deployment is affordable.
   First step: Run a 4-bit quantised open model on a single consumer GPU and measure whether it can reliably extract measurements from 50 anonymised sample reports.
