BUSINESS IDEAS
1. Agent test-fixture store for Spring Boot services (score 4.8; effort 2, cost 1, fit 5)
   A Spring Boot starter where customer-level test cases live as versioned data files outside the code, so AI coding agents cannot edit the expected behaviour. Sold as an open-source starter with a paid CI dashboard for teams.
   Why now: Matteo Vaccari argues that tests stored as data become the contract with AI-written code, and GitHub's push toward thousands of concurrent agents makes unreviewed agent edits a growing risk.
   First step: Convert one existing controller test suite into a YAML fixture format and write a JUnit runner that loads it, then publish it as a public repo.

2. Payout-rail adapter for Indian employers using UPI and IMPS fallback (score 4.2; effort 3, cost 2, fit 5)
   A small API that sends employee reimbursements and benefit payouts over the cheapest working bank rail, with bank account validation and a retry-safe ledger. Sold to Indian SMEs and HR-tech tools that currently pay through a single expensive gateway.
   Why now: Versine's MCP wallet for agent-initiated transfers and group payouts shows the market moving toward programmable money movement, and Indian employers still lack a simple, cheap payout API for claims.
   First step: Write a one-page spec listing five HR tools or SaaS vendors that need reimbursements paid out, and ask two of them what they pay per transfer today.

3. Cost-budgeted model router library for Indian SaaS teams (score 4.0; effort 3, cost 1, fit 4)
   A Java or Python library that assigns a fixed monthly token budget across requests and routes each to a cheaper or stronger model, with a dashboard showing spend per feature. Sold as a self-hosted library with a paid support tier.
   Why now: CoordRoute shows that per-request routers ignore total budget, and a shared-budget allocator is a concrete gap that small teams running several LLM features can fill.
   First step: Build a 100-line prototype that splits a daily budget across three mock request types and prints the cost per type, then share it with two engineers who run LLM features.

4. Agent memory and handoff store for clinic workflows (score 3.8; effort 3, cost 2, fit 4)
   A hosted service that keeps per-patient and per-clinic state for AI assistants (open follow-ups, pending lab reviews, who was contacted) with audit logs, so agents can resume work without re-reading whole charts. Sold to small clinic chains and clinic software vendors.
   Why now: Beacon Health's founders are building agents to catch patient care that slips through gaps, and a TASK Memory paper reports that memory-ignoring hits up to 46% of queries, so clinics need reliable state rather than prompt stuffing.
   First step: Interview three clinic front-desk or follow-up coordinators about the last missed follow-up they had, and write down what information they wished they had on screen.

5. Radiology report draft reviewer for small imaging centres (score 3.8; effort 3, cost 2, fit 4)
   A tool that takes a radiologist's dictated or drafted report and checks it against the study's structured fields, flagging missing measurements, laterality mismatches and template gaps, while the radiologist signs off. Sold per report or per seat to diagnostic centres in India.
   Why now: STAT's coverage of AI drafting radiology reports ahead of RSNA shows the drafting step is arriving, and the review and liability step is the part that needs tooling that keeps the radiologist in charge.
   First step: Collect five anonymised report templates from a diagnostic centre contact and list the fields a checker would need to validate.
