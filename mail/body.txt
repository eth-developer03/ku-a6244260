BUSINESS IDEAS
1. Blast-radius check for Spring Boot dependency upgrades (score 4.5; effort 3, cost 1, fit 5)
   A GitHub Action for Maven or Gradle Java repos that, when a dependency or JDK version changes, lists every internal consumer module and call site that would break. It also flags whether a patched version is actually deployed. Sold as a per-seat tool for teams with many internal libraries.
   Why now: Netflix released Quasar to measure cross-repo blast radius of Java API changes, and Java4Shell is pushing teams to patch quickly with less time to check.
   First step: Write a Maven plugin that diffs public method signatures between two versions of one library and lists its callers in a sample multi-module project.

2. Reproducible eval kit for hospital AI vendor claims (score 4.2; effort 2, cost 1, fit 4)
   A small open-source harness and hosted report that lets a hospital run a vendor's clinical AI against its own de-identified Indian-language notes and get a versioned, rerunnable score. Hospitals buy the report, and the clinicians decide what to trust. It does not give any medical advice.
   Why now: MedCity News argues that vendor exam scores mislead buyers, and health systems now need open, reproducible and continuously updated evaluation before deployment.
   First step: Write a 50-case evaluation set from public or consented de-identified notes and publish a scoring script that reruns any model endpoint against it.

3. Test selection for agent-generated pull requests (score 4.0; effort 3, cost 1, fit 4)
   A GitHub Action for Java and Maven monorepos that runs only the tests affected by each PR's changed files and stores customer-level tests as data files the agent cannot edit. It targets mid-size Indian product teams whose CI costs are rising. Sold as a flat monthly fee per repo.
   Why now: StarSling's YC launch cut slow CI runs by about half for agent-heavy repos, and Vaccari argues AI-written code needs tests held outside the agent's reach.
   First step: Take one open-source Maven project, build a script that maps changed files to affected test classes, and measure the CI time saved on 20 past commits.

4. Lab and discharge report digitiser for Indian clinics (score 3.8; effort 3, cost 2, fit 4)
   A per-clinic upload tool that turns scanned lab reports and handwritten discharge papers into structured records the clinic's existing EMR or spreadsheet can import. The doctor reviews and confirms every field before it is saved. Sell a flat monthly plan per clinic.
   Why now: Apollo and Microsoft are using AI to rebuild fragmented hospital records, which shows Indian providers are now funding record-digitisation work and not only pilots.
   First step: Interview five clinic front-desk staff in one neighbourhood and collect 20 real scanned reports, noting which fields they re-type by hand.

5. Employee medical reimbursement payouts over UPI and IMPS (score 3.0; effort 4, cost 4, fit 4)
   A B2B API that lets Indian employers run HSA/FSA-style medical claim reimbursements, with claim intake, a policy check and a payout to the employee's bank account through a licensed payout partner. Charge per payout or as a per-employee monthly fee.
   Why now: Flex's founder built the company after personally hitting HSA and FSA payment failures, which shows the benefits-payout problem is real enough to fund a startup.
   First step: Call two mid-size Indian employers' HR or finance leads and ask how reimbursements are paid today and what breaks each month.
