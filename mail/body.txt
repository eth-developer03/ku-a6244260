BUSINESS IDEAS
1. Discharge summary drafter for Indian private hospitals (score 4.2; effort 3, cost 2, fit 5)
   A Spring Boot service that takes a structured inpatient record (admission notes, labs, medication orders, procedures) and drafts a discharge summary for the treating doctor to edit and sign. Sold per-bed or per-discharge to mid-size hospitals and multi-specialty chains that still hand-write summaries.
   Why now: A new npj Digital Medicine study shows AI can help with discharge summaries for long, complex stays, which gives hospital buyers evidence to point to when they ask for a pilot.
   First step: Using your internship contacts, shadow one discharge workflow with consent and list the five fields the doctors rewrite most often by hand.

2. Pre-commit secret guard for agent-written code (score 4.2; effort 2, cost 1, fit 4)
   A CLI and pre-commit hook that scans diffs, agent config files and shell history for credentials, then blocks the commit and suggests rotation steps. It is sold to fintech and payments startups in India that let coding agents touch their repositories. Pricing is per developer per month.
   Why now: A report found Claude Code's 'Don't Ask Again' option left passwords in over a thousand public GitHub files, and the Chainalysis breach shows attackers take credentials for every customer at once.
   First step: Write a Git pre-commit hook using gitleaks rules plus checks for agent permission files, then run it on five public repos to measure false positives.

3. Doctor-reviewed patient timeline for clinic follow-ups (score 4.0; effort 3, cost 1, fit 4)
   A small web tool that turns scattered visit notes, lab values and medication changes into a dated, per-patient timeline the doctor reviews before each follow-up. It keeps facts attributed to the right patient and surfaces records that are out of date. The doctor makes every clinical decision; the tool only organises what was recorded. Sold as a SaaS to single-doctor clinics and small polyclinics.
   Why now: A new arXiv paper on graph memory for medical dialogue shows that outdated state and cross-patient leakage are the failure modes that make long-term patient records hard to trust.
   First step: Build a prototype with synthetic patient records only, then ask a clinic you know to rate whether the timeline saves time before the next visit.

4. Agent regression QA service for Indian SaaS teams (score 4.0; effort 3, cost 1, fit 4)
   A hosted service where a team gives you its staging URL and user flows, and an agent explores the app and writes Playwright regression tests that run in CI. Priced monthly per project, aimed at small Indian SaaS and D2C teams that ship often but cannot afford a QA hire.
   Why now: Momentic's YC launch shows buyers accept agents that explore apps to find bugs, and the founders tie this to rising change failure rates from LLM-written code.
   First step: Pick one open-source Spring Boot or React app, have an agent generate Playwright tests for its main flows, and record how many real bugs it finds in a week.

5. Scoped tool-call gateway for MCP and agent workloads (score 3.5; effort 4, cost 2, fit 4)
   A proxy that sits between an agent and its MCP servers or internal APIs. It enforces per-tool allowlists, short-lived scoped tokens, kill switches and an append-only audit log, so the team can see and stop what each agent did. Sold as a self-hosted Docker image with a flat yearly license to small B2B SaaS teams.
   Why now: Edera's new bounded-authority model separates what an agent may do from the credentials it holds, and GitHub's agent-scale Git storage shows that many agents now write to shared systems at once.
   First step: Build a Spring Boot filter that wraps three internal tool endpoints, enforces an allowlist and writes each call to Postgres, then demo it to one team that runs agents in production.
