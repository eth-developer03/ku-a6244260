Each run replays the cases against a Spring Boot service and fails the build on any behavioural change. It is sold as a free core with a paid hosted dashboard to teams using Copilot or Claude Code on Java backends.
Effort 2/5 · Cost 1/5 · Fit 4/5 (lower effort and cost are better)
Why now: Fowler's post on tests as data argues that AI-written code needs an external contract the agent cannot change, and deterministic simulation testing shows how to make such failures reproducible in distributed backends.
First step: Take one Spring Boot endpoint, export ten request and response pairs as JSON files in a separate folder, and write a JUnit runner that replays them and fails on any diff.

Effort 3/5 · Cost 1/5 · Fit 4/5 (lower effort and cost are better)
