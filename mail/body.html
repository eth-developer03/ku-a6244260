#3 Doctor-reviewed patient timeline for clinic follow-ups4.0
↻ repeat signal · 5 days
A small web tool that turns scattered visit notes, lab values and medication changes into a dated, per-patient timeline the doctor reviews before each follow-up. It keeps facts attributed to the right patient and surfaces records that are out of date. The doctor makes every clinical decision; the tool only organises what was recorded. Sold as a SaaS to single-doctor clinics and small polyclinics.
Effort 3/5 · Cost 1/5 · Fit 4/5 (lower effort and cost are better)
Why now: A new arXiv paper on graph memory for medical dialogue shows that outdated state and cross-patient leakage are the failure modes that make long-term patient records hard to trust.
First step: Build a prototype with synthetic patient records only, then ask a clinic you know to rate whether the timeline saves time before the next visit.

Effort 3/5 · Cost 1/5 · Fit 4/5 (lower effort and cost are better)

#5 Scoped tool-call gateway for MCP and agent workloads3.5
↻ repeat signal · 4 days
A proxy that sits between an agent and its MCP servers or internal APIs. It enforces per-tool allowlists, short-lived scoped tokens, kill switches and an append-only audit log, so the team can see and stop what each agent did. Sold as a self-hosted Docker image with a flat yearly license to small B2B SaaS teams.
Effort 4/5 · Cost 2/5 · Fit 4/5 (lower effort and cost are better)
Why now: Edera's new bounded-authority model separates what an agent may do from the credentials it holds, and GitHub's agent-scale Git storage shows that many agents now write to shared systems at once.
First step: Build a Spring Boot filter that wraps three internal tool endpoints, enforces an allowlist and writes each call to Postgres, then demo it to one team that runs agents in production.
