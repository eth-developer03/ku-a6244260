#1 Blast-radius check for Spring Boot dependency upgrades4.5
A GitHub Action for Maven or Gradle Java repos that, when a dependency or JDK version changes, lists every internal consumer module and call site that would break. It also flags whether a patched version is actually deployed. Sold as a per-seat tool for teams with many internal libraries.
Effort 3/5 · Cost 1/5 · Fit 5/5 (lower effort and cost are better)
Why now: Netflix released Quasar to measure cross-repo blast radius of Java API changes, and Java4Shell is pushing teams to patch quickly with less time to check.
First step: Write a Maven plugin that diffs public method signatures between two versions of one library and lists its callers in a sample multi-module project.

#3 Test selection for agent-generated pull requests4.0
↻ repeat signal · 8 days
A GitHub Action for Java and Maven monorepos that runs only the tests affected by each PR's changed files and stores customer-level tests as data files the agent cannot edit. It targets mid-size Indian product teams whose CI costs are rising. Sold as a flat monthly fee per repo.
Effort 3/5 · Cost 1/5 · Fit 4/5 (lower effort and cost are better)
